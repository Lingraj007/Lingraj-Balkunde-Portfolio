## About This Portfolio

This site is my introduction to recruiters, hiring managers, and fellow developers. It walks through who I am, what I can build, and how to reach me — built entirely with plain HTML, CSS, and JavaScript so the source code itself is easy to read and review.

## Tech Stack

- **HTML5** — semantic structure
- **CSS3** — custom properties (CSS variables) for theming, responsive grid/flexbox layouts, no framework
- **JavaScript (Vanilla)** — mobile navigation toggle, contact form submission handling
- **Fonts** — [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [Inter](https://fonts.google.com/specimen/Inter), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) via Google Fonts
- **Formspree** — handles contact form email delivery without a backend server
- **Hosting** — [GitHub Pages](https://pages.github.com/)

## Design

- **Theme:** Dark, minimal, black-and-white base with a single gold/amber accent color
- **Style:** Clean, professional, and readable — built to be recruiter-friendly and easy to skim on any device
- **Responsive:** Fully responsive layout with a dedicated mobile navigation menu
